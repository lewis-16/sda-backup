# sEEG 事件标签保留与删除说明

本文档基于 `sEEG_check_output.txt` 中整理的各段记录事件类型，规定在后续分析或清洗中**需要保留**与**需要删除**的事件标签规则。

---

## 一、需要保留的事件类型（仅保留以下三类）

### 1. 癫痫发作（Seizure）

- **保留标签（精确或包含）：**
  - `◆发作`（含变体如 `◆发作1`、`◆发作？` 等）
  - `end`（发作结束标记）
  - `END`（大写形式，同发作结束）
  - `发作`（单独出现时视为发作相关）

- **说明：** 用于标记临床发作的起止或发作事件本身，与发作期分析直接相关。

---

### 2. 癫痫间期放电（Interictal discharge）

- **保留规则：** 无固定字符串，一般为**通道名或通道组合**形式的标签。
- **典型形式：**
  - 单通道：`A`、`B`、`C`、`D`、`E`、`F`、`G`、`H` 等
  - 多通道组合：`ABC`、`ABCDEGH`、`ABCDGH`、`ABCE`、`AD`、`ADFG`、`ADFH`、`ADH`、`AH`、`ABCEFG`、`ABEFG`、`BEFG`、`EFG`、`a`、`adfg`、`adgf`、`fg`、`h` 等

- **说明：**
  - 字母组合对应 SEEG 通道名，大小写均可能出现（如 `ABC`、`abc`、`abchjk`）。
  - 凡符合“仅为字母组合、无其它固定前缀/后缀”的通道名形式，均视为间期放电，**保留**。

---

### 3. 刺激阶段放电（Stimulation-related）

- **保留规则（满足其一即可）：**
  - 标签中**包含 `Stim`**（不区分大小写）：  
    如 `Stim Start F2-F1 1.0`、`Stim Stop G4-G3 3.0`、`Stim Start D10-D9 1.` 等。
  - **含有症状学描述**的标签（即对临床表现的文字描述）：  
    如 `四肢用力、脸红`、`无明显临床症状`、`肢体快速抖动`、`身体快速抖动`、`左眼紧闭，大喊、双下`、`叫家长`、`身体蜷缩，双下肢蹬踏`、`头抖一下伴左上肢外展`、`右上肢抖一下`、`家长指认事件`、`听到的声音变小`、`双侧眼睑肌电爆发`、`口角右歪`、`口角抖一下`、`口角抖动`、`口角抖动一下`、`发声`、`口角抽动`、`睁眼、口角歪，头眼右`、`左下肢节律性抖动`、`找家长、右侧眼睑抖动`、`下肢蹬踏`、`不舒服，描述不出来`、`自述发作了` 等。

- **说明：**
  - 含 `Stim` 的标签用于标记刺激开始/结束，与刺激及刺激诱发放电分析相关。
  - 症状学描述与刺激或发作的临床表现对应，需**保留**以便与电生理对照。

---

## 二、需要删除的事件类型（除上述三类外均删除）

以下为数据中常见且**应统一删除**的标签类型（凡不属于“发作”“间期放电”“刺激/症状学”的均按此类处理）：

| 类型           | 示例 |
|----------------|------|
| 时间/数值标记  | `+0.000000`、`+158.000000`、`+195.000000` 等所有 `+数字` 形式 |
| 参考电极关断   | `A1+A2 OFF` |
| 记录段标记     | `Segment: REC START 于涵双 EEG`、`Segment: REC START 周子娴双 E` 等 |
| 复位标记       | `RESET OFF`、`RESET ON` |
| 仅符号无文字   | 单独的 `◆`（不含“发作”等文字） |
| 与记录质量相关 | `EEG好！`、`EEG好！！` |
| 操作/误标记   | `误打`、`◆视频好！！`、`找家长`（仅此二字且无其它症状学描述时）等 |

- **原则：** 未在“一、需要保留的事件类型”中明确覆盖的标签，一律**删除**。

---

## 三、判断流程小结

对每一个事件标签依次判断：

1. 是否为**癫痫发作**相关？  
   → 是：`◆发作`、`end`、`END`、`发作` 等 → **保留**
2. 是否为**间期放电**（通道名/通道组合）？  
   → 是：仅由字母组成的通道名形式 → **保留**
3. 是否为**刺激或症状学**？  
   → 是：含 `Stim` 或为症状学描述文本 → **保留**
4. 以上皆否 → **删除**

---

## 四、与 `sEEG_check_output.txt` 的对应关系

- `sEEG_check_output.txt` 中列出的“事件类型”来自多段 sEEG 记录的汇总；同一“事件类型”可能在不同患者/不同文件中重复出现。
- 本说明中的“保留/删除”规则适用于**所有**出现在该汇总中的事件类型，以及后续新增的、符合上述描述的标签。
- 实施时建议：先按本规则对每条事件的标签字符串做分类，再仅保留上述三类，其余从事件表或导出结果中删除。
