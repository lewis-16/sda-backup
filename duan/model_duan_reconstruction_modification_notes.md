# Model Duan Reconstruction 修改说明

## 修改日期
2025年10月10日

## 修改目标
将模型从72个朝向相关的类别（24个对象 × 3个朝向）改为24个对象类别，即不考虑朝向因素。基于生物学观察：神经元对朝向的反应不强，因此所有朝向的刺激都使用正朝向（0度）的图片作为重建目标。

## 修改内容详解

### 1. 标签映射函数 `create_angle_mapping()`

**修改前:**
- 为每个对象的每个朝向创建独立的类别
- 共72个类别：24个对象 × 3个朝向 = 72

**修改后:**
- 将同一对象的所有朝向映射到同一个类别ID
- 共24个类别：只区分对象，不区分朝向
- 示例：
  ```
  Dee1_0   → 类别 0
  Dee1_45  → 类别 0  (相同)
  Dee1_315 → 类别 0  (相同)
  Ele_0    → 类别 1
  Ele_45   → 类别 1  (相同)
  ...
  ```

**代码变化:**
```python
# 为每个对象的所有朝向分配相同的类别ID
for angle in angles:
    angle_mapping[f"{img}_{angle}"] = object_idx

# 每个对象只增加一次索引
object_idx += 1
```

### 2. 数据集类 `TrailActivityDataset`

**修改位置:** `__init__` 方法中构建数据时

**修改前:**
- 根据 `trial_target` 确定图片的实际朝向（0/45/315度）
- 加载对应朝向的图片

**修改后:**
- 仍然根据 `trial_target` 记录原始朝向（用于标签映射）
- 但**始终加载0度图片**作为重建目标
- 对于 shape2d 类别，始终使用 B1（相当于基准颜色）

**代码变化:**
```python
# 记录原始的角度信息（用于标签映射）
if category == 'shape2d':
    if trial_target == 1:
        angle = 'B1'
    elif trial_target == 2:
        angle = 'G1'
    elif trial_target == 3:
        angle = 'R1'
else:
    if trial_target == 1:
        angle = '0'
    elif trial_target == 2:
        angle = '315'
    elif trial_target == 3:
        angle = '45'

# 修改：始终使用0度（或B1）的图片作为重建目标
if category == 'shape2d':
    image_angle = 'B1'  # shape2d类别使用B1作为默认
else:
    image_angle = '0'   # 其他类别使用0度作为默认

image_path = os.path.join(self.obj3d_root, category, f"{image_name}_{image_angle}.png")
```

### 3. 模型配置更新

**EP Encoder 配置:**
```python
num_object_classes = len(set(angle_mapping.values()))  # 24

ep_config = ModelConfig(
    ...
    num_classes=num_object_classes,  # 从72改为24
    ...
)
```

**VAE-VAR 模型:**
```python
vae, var = build_vae_var(
    ...
    num_classes=num_object_classes,  # 从72改为24
    ...
)
```

**Training Config:**
```python
var_config = {
    "num_classes": 24,  # 从72改为24
    ...
}
```

## 修改影响

### 数据层面
- **输入（神经活动）**: 保持不变，仍然是不同朝向刺激对应的神经活动
- **输出（重建目标）**: 统一为0度图片
- **标签**: 同一对象的不同朝向共享相同的类别标签

### 模型层面
- **类别数**: 从72减少到24
- **模型容量**: 可以保持不变或适当减小
- **学习目标**: 学习从神经活动中提取对象特征，而非朝向特征

### 训练效果预期
1. **简化任务**: 类别数减少使学习任务更简单
2. **对象特征**: 模型将学习到更纯粹的对象表示
3. **朝向不变性**: 模型被迫学习朝向不变的特征
4. **收敛速度**: 可能更快收敛，因为任务更简单

## 生物学意义

### 神经科学依据
1. **IT皮层的朝向不变性**: 下颞叶皮层（IT cortex）的神经元对物体朝向的反应相对较弱，更关注物体本身的特征
2. **高层视觉表示**: 在视觉层级的高层，神经元倾向于编码物体的本质特征而非低层次的几何变换（如旋转）
3. **行为学证据**: 灵长类动物能够轻松识别不同朝向的同一物体，说明大脑学习了朝向不变的表示

### 实验假设
如果修改后的模型能够成功重建0度图片（即使输入是45度或315度刺激对应的神经活动），这将支持以下假设：
- 记录的神经元群体主要编码物体身份而非朝向信息
- 神经表示具有朝向不变性
- 不同朝向的同一物体激活了相似的神经模式

## 使用方法

1. **直接运行修改后的文件:**
   ```bash
   python model_duan_reconstruction.py
   ```

2. **观察输出:**
   程序会打印以下信息：
   - 对象分类数量（应为24）
   - 总标签数（应为72，包含所有朝向）
   - 模型配置信息

3. **验证修改:**
   检查输出的PDF重建结果，所有重建的图片应该都是0度朝向

## 注意事项

1. **数据结构假设**: 
   - 代码假设每个对象有3个朝向（0, 45, 315度）或3种颜色（shape2d）
   - 如果数据结构不同，需要相应调整

2. **标签一致性**:
   - 虽然图片统一为0度，但标签映射仍然保留原始朝向信息
   - 同一对象的不同朝向会映射到相同的类别ID

3. **评估指标**:
   - 重建质量评估时，所有样本都与0度图片比较
   - 可能需要单独分析不同原始朝向的重建效果

4. **预训练模型**:
   - 如果使用预训练的VAE权重，确保加载正确
   - VAR模型需要重新训练，因为类别数改变了

## 未来改进方向

1. **朝向分析**: 可以分别统计原始45度、315度刺激的重建效果，看是否存在差异
2. **梯度可视化**: 分析模型是否真的忽略了朝向相关的神经活动特征
3. **对比实验**: 可以与原始72类别模型对比，定量评估朝向不变性
4. **跨朝向泛化**: 测试模型在不同朝向之间的泛化能力
